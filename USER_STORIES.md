# Consentrail — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### DPO / privacy lead

- As a DPO, I want a dashboard of the five readiness areas with evidence gaps, so that GDPR programmes are not slideware.
- As a DPO, I want consortium roles recorded before go-live, so that “who is the DPO?” is answered.
- As a DPO, I want withdrawal of consent to propagate processing-stop flags, so that lawfulness is operational.

### Consent / rights operator

- As a consent operator, I want clinical-trial-grade consent workflows with fine-grained share parameters, so that research exchanges are auditable.
- As a rights operator, I want portability packs assembled from member evidence references, so that data-subject rights are fulfilable across the network.
- As a rights operator, I want erasure cases to orphan hashes after off-chain delete, so that immutability does not block GDPR.

### Compliance / regulator liaison

- As a compliance analyst, I want obligation contracts to alert on DPA term breaches, so that accountability is continuous.
- As a regulator liaison, I want supervisor read views without PD, so that Guernsey-style transparency is possible.
- As a compliance analyst, I want integrity proofs for process artefacts, so that we can show records were not manipulated.

### Security officer

- As a security officer, I want monitoring of ledger-connected app access and key events, so that blockchain does not create a new blind spot.
- As a security officer, I want participant impersonation checks, so that permissioned networks stay permissioned in practice.

### Consortium governor

- As a governor, I want owner-mediated authorisations before health/KYC evidence moves, so that self-sovereign control is real.
- As a governor, I want triple-blind exchange modes for attribute verification, so that SecureKey-style privacy holds.
